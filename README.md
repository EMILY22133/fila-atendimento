# 📋 Sistema de Fila de Atendimento

 Sistema web para gerenciamento de fila de atendimento, desenvolvido com **Python, Flask e SQLite**.

 ## 🚀 Funcionalidades

 - Cadastro de clientes
- Fila de atendimento
- Chamada do próximo cliente
- Status: Aguardando, Em Atendimento e Concluído
- Cancelamento de atendimento
- Prioridade Normal e Preferencial
- Histórico de atendimentos
- Atualização automática da fila

 ## 🛠️ Tecnologias

 - Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

 ## 📂 Estrutura do projeto

```
fila-atendimento/
├── app.py
└── requirements.txt
```

 O banco de dados `fila.db` é criado automaticamente ao executar o sistema.

 ## ▶️ Como executar

 Instale as dependências:

```
pip install -r requirements.txt
```

 Execute o projeto:

```
python app.py
```

 Acesse no navegador:

```
http://127.0.0.1:5000
```
